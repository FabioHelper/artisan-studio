# SPEC-08: MCP Evidence Integrity (P0.5)

Source plan: `.bridge/ARTISAN-MCP-EVIDENCE-INTEGRITY-PLAN.md` (P0.5 = the evidence instrument; P0.6 `BUILD-AUTHORED-BUDGET` = authored-world budget conformance, planned after P0.5 lands). Both block `BUILD-CREATIVE` (P1).

## 1. Objective
Every piece of evidence the MCP returns (compile acknowledgement, screenshot, engine telemetry, telemetry export, performance audit) must belong, provably, to the world the LLM authored, or be labeled as something else, or be refused. A second MCP instance must never lose the live bridge silently. Captures must show the canvas only and land where they were asked to land. Audits report what they measured, never repairs they did not perform.

## 2. Identity model
| Identity | Scope | Generated by | Rule |
|---|---|---|---|
| `instanceId` | one MCP process | `crypto.randomUUID()` in `bridge.js` | Shown in `artisan://capabilities`, `GET /api/bridge/identity`, every bridge message, the Studio indicator (first 8 hex digits) and every evidence envelope. |
| `connectionId` | one WebSocket | bridge (`conn-<n>`) | Sent in `BRIDGE_HELLO`; listed in capabilities. |
| `clientId` | one Studio page load | browser `crypto.randomUUID()` | Sent in `BRIDGE_HELLO_ACK` and every reply. |
| `sceneIdentity` (authored) | manifest content | `sha256:` + first 32 hex of SHA-256(`canonicalJson(manifest)`) | Bytes unchanged from P0 (`WorldSession.sceneIdentity`). |
| `sceneIdentity` (measured) | what a renderer shows | the browser recomputes it from the manifest it compiled | Presets are `preset:<id>`, game mode is `mode:game`, nothing loaded is `none`. These namespaces can never equal a `sha256:` identity. |
| `epoch` | render state of one page | browser counter, +1 on every scene swap | A capture or audit whose epoch changed start→end is invalid. |

Canonical helpers live in `src/contracts/artisanContract.js` (additive): `BRIDGE_PROTOCOL = 2`, `SCENE_IDENTITY_PREFIX`, `SCENE_IDENTITY_HEX_CHARS = 32`, `formatSceneIdentity(hex)`, `async computeSceneIdentity(manifest, subtle)`. Without `crypto.subtle` (insecure context) the browser reports `sceneIdentity: null, identityError: 'INSECURE_CONTEXT'` and the server refuses to verify.

## 3. Bridge (protocol v2, loopback only, origin/host policy unchanged)
- The first instance to bind the configured port (default 3456) owns the live bridge. There is no automatic port switching.
- On `EADDRINUSE` the instance enters state `conflict`, stays alive on stdio, probes `GET /api/bridge/identity` (1.5 s, strict shape) to classify the owner as `artisan` (instanceId, pid, startedAt, world), `artisan-legacy` (the pre-v2 "Artisan 3D Preview Bridge" page) or `foreign`, logs a CONFLICT banner to stderr, and reports `previewBridge.state: 'conflict'`, `owner` and `remediation` in capabilities. `compile_preview` fails with `BRIDGE_CONFLICT`, naming the port, the owner and this instance, and both fixes (stop the owner, or relaunch with `MCP_WS_PORT=<free port>` and open the Studio with `?mcpPort=<port>&mcpInstance=<instanceId>`). Headless evidence stays available and says so.
- Lazy re-acquire: before a live-dependent operation in `conflict`, the instance retries `listen()` once. No background timers.
- `ARTISAN_BRIDGE=off` is state `disabled`: `compile_preview` stays ok with `livePreview: false`.
- Handshake: on connect the server sends `BRIDGE_HELLO {protocol, instanceId, connectionId, pid, port, startedAt, serverVersion}` before `cabinet_init`. The browser answers `BRIDGE_HELLO_ACK {protocol, instanceId, connectionId, clientId, pinnedInstance, render}`. Only a matching ACK makes a connection **verified**. Unverified sockets receive vault messages only, never commands or `WORLD_UPDATE`.
- Pinning: a page opened with `?mcpInstance=<id>` closes with code 4002 and shows `MCP: WRONG INSTANCE (<port>)` when the HELLO disagrees. A verified page shows `MCP: CONNECTED (<port> · <first 8 hex>)`; a page that receives no HELLO within 2 s shows `MCP: CONNECTED (<port> · UNVERIFIED legacy)` and keeps the legacy bare-manifest behavior.
- Commands carry `{type, id, instanceId}`; replies carry `{type, id, instanceId, clientId, render: {sceneIdentity, epoch, worldId, version, renderedEntityIds}}`. A pending request resolves only on a reply of the expected type from the same socket it was sent to; for every command except the compile, a reply with a foreign `instanceId` or `clientId` is ignored. The compile resolves on the same-socket reply and the server verifies every field (§5).
- `MANIFEST {id, instanceId, expect, manifest}` goes to all verified clients; the first verified ack's client becomes the **primary client** for later commands. `commitCandidate` publishes `WORLD_UPDATE {instanceId, manifest}` to verified clients (no reply). The browser handles bridge messages through one serialized queue.
- `GET /api/bridge/identity` returns `{service: 'artisan-mcp-bridge', protocol, instanceId, pid, startedAt, port, serverVersion, verifiedClients, world: {worldId, version, sceneIdentity, entityCount}}`, never manifest content.

## 4. One render path in the browser (`src/main.js`, exported on `window.__artisan`)
`applyAuthoredManifest(manifest)` (the extracted bridge manifest handler: lighting preset, authored lighting, compile, group swap, practical light, profile, shadow bake) computes the identity before compiling, sets the render state, increments `epoch` and returns `{sceneIdentity, worldId, version, manifestEntityCount, renderedEntityIds}` (the names of the entity groups under `activeWorldGroup`). The live `MANIFEST`, `WORLD_UPDATE` and the headless runner all call it. `getRenderState()`, `waitForSettled({quietFrames: 10, timeoutMs})` (warm-up and shadow-bake counters at 0 for 10 consecutive frames), `measureRender({frames})` (max draws and triangles, mean and p95 frametime, `fps = 1000/mean`, GPU, software-rasterizer flag, pixel ratio, viewport, camera) and `captureCanvas({angle})` (render and `toDataURL` in the same task; fails if the epoch changed) complete the surface. The compile ack reports draws and triangles after settling, so shadow-bake passes are excluded.

## 5. Evidence resolution (identical for screenshot, engine telemetry, telemetry export and audit)
1. `scene` given (screenshot/audit): render the preset; evidence is `preset:<id>`, `authored: false`, with no authored identity or manifest attached.
2. Otherwise the target is the authored world:
   - bridge `listening` with a verified primary client: ask the browser; proceed only if its measured `sceneIdentity` equals the session identity and `renderedEntityIds` set-equals the manifest ids, else `PREVIEW_STALE` (no automatic re-push, no source switch);
   - otherwise (no verified client, `conflict`, `disabled`): headless authored render. `HeadlessRunner.renderEvidence` injects the manifest through a `page.evaluate` argument, requires the browser-computed identity and entity set to equal the session's, and only then writes artifacts; on mismatch `HEADLESS_IDENTITY_MISMATCH`, nothing written.
3. Every evidence response carries `evidence: {sceneIdentity (measured), identityVerified, authored, source, worldId, version, entityCount, renderer: {kind, instanceId, clientId, connectionId, headlessRunId}, camera, measuredAt, bridge: {state, owner?}}`. The top-level `sceneIdentity` of an evidence output is always the measured one.
4. `import_telemetry_logs` writes `{timestamp, evidence, telemetry, manifest}` only when `identityVerified === true`, else `EVIDENCE_UNVERIFIED` and no file.
5. `get_telemetry` stays session state (authored) and adds `lastVerifiedRender: {sceneIdentity, source, instanceId, clientId, at}`.

The compile ack is verified field by field (same socket, `instanceId`, `clientId`, `ok`, browser-computed `sceneIdentity`, `worldId`, `version`, `renderedEntityIds.length === entityCount === manifest.entities.length` with set-equal ids); any failure is `ACK_MISMATCH` with one issue per field. `withinBudget` is computed from settled numbers (draws ≤ profile max and triangles ≤ profile target) and is `null` when not settled.

## 6. Error codes
New: `BRIDGE_CONFLICT`, `STUDIO_UNVERIFIED`, `ACK_MISMATCH`, `PREVIEW_STALE`, `EVIDENCE_UNVERIFIED`, `HEADLESS_IDENTITY_MISMATCH`, `STUDIO_UNREACHABLE` (maps `net::ERR_CONNECTION_REFUSED`). Existing: `INVALID_FILENAME`, `ARTIFACT_PATH_ESCAPE`, `COMPILE_FAILED`, `PROFILER_UNAVAILABLE`.

## 7. Capture and artifact rules
- Every capture is canvas-sourced (`captureCanvas`); `HeadlessRunner` makes no `page.screenshot` call. The headless camera is `angle` if given, else `hero` for authored worlds; presets keep their own camera.
- `safeArtifactRelPath(requested, ext, fallbackStem)` (in `artifacts.js`, the only fs-mutating MCP module) accepts at most 4 segments split on `/` or `\`, sanitizes each segment, and rejects with `INVALID_FILENAME` (never silently rewritten) absolute paths, drive letters, UNC paths, `.`/`..` segments, Windows reserved names, empty segments, segments over 64 chars and totals over 120 chars. It creates missing directories itself, enforces realpath confinement (junctions and symlinks cannot escape) and reports `normalized: true` when characters were substituted. `safeArtifactPath` keeps its basename semantics for internal fixed names.
- Capture responses return `requestedFilename`, `path`, `bytes`, `pngSha256`, `width` and `height`.

## 8. Audit semantics (`src/engine/ArtisanProfiler.js`)
`smokingGuns[]` keeps `culprit`, `severity`, `impactMs`, `jitterMs`, drops the canned `actionTaken`/`rootCause` narratives, and adds `observation`, `recommendation` (explicitly not applied), `status: 'OBSERVED'` and `repairApplied: false`. The verdict is `OBSERVED <n> FINDING(S) ABOVE THRESHOLD` or `NO FINDING ABOVE THRESHOLD`, with `baselineFps` measured. `device.gpu` is the real renderer string and `device.webglVersion` replaces the literal; `gpuRenderer` stays as a GPU-string alias. The report carries `scene: {sceneIdentity, epochStart, epochEnd, entityIds}` and `restoredState: {pixelRatioBefore, pixelRatioAfter, ok}`; every mutated renderer setting is restored exactly.

## 9. Budget
Tools stay at 13 with unchanged input schemas; `JSON.stringify(tools).length ≤ 7,960` chars. No new dependencies.

## 10. Verification and acceptance
One command: `node scripts/verify_mcp_evidence_integrity.mjs` (hermetic ports, own Vite, headless browser, report at `.artisan-artifacts/verify-evidence/latest/evidence_integrity_report.json`). `overall = integrity && budgetInstrument && p0` closes P0.5 (A-1..A-11). `authoredBudget` (unmodified replay world ≤ 30 draws and ≤ 15,000 triangles, A-12) is always printed and recorded, never folded into `overall`; it is owned by P0.6 and blocks P1.
